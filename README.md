# LLM-API-call

agree one small feature, make one real LLM API call, and explain what was sent, what came back and what it cost.
Cost = input tokens × input rate + output tokens × output rate, using the model’s current prices. Tokens are small pieces of text.

sign up to all or one of them to get an API key
https://platform.openai.com
https://platform.claude.com/
https://openrouter.com
https://requesty/ai

once you have the API key, save it as .env file (text file called .env)
then point Claude to the file, and prompt "create a simple application that calls the LLM (depending on which provider you selected): set up the system prompt and get a response back. Create also a simple UI that displays the response"
